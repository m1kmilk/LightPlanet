# Arduino Uno 虚拟星球光影系统

本项目通过 USB 串口把 Arduino Uno 的模拟光线传感器数值传到 Chrome 网页。网页没有服务器、Node.js、蓝牙或外部依赖。

## 硬件接线清单

| 光线传感器引脚 | Arduino Uno 引脚 | 说明 |
|---|---|---|
| VCC | 5V | 供电正极 |
| GND | GND | 供电负极，必须共地 |
| OUT / AO | A0 | 模拟信号输出 |

传感器型号不同，亮暗方向可能相反。本项目按题设的“数值低为强光、数值高为黑暗”设计；如果实际方向相反，可在网页的 `applyLight()` 函数中把 `const brightness=1-v/1023` 改为 `const brightness=v/1023`。

## 使用方法

1. 安装 Arduino IDE，使用 USB 数据线连接 Uno（只充电线无法通信）。
2. 打开 `LightPlanet.ino`，在 Arduino IDE 的“工具”中选择 `Arduino Uno` 与正确端口，上传程序。
3. 上传完成后，关闭 Arduino IDE 的串口监视器和串口绘图器，避免它们占用端口。
4. 用桌面版 Chrome 打开 `index.html`，点击“连接 Arduino 串口”。在系统窗口选择 Uno 对应的串口并授权。
5. 遮挡和照亮光线传感器观察星球变化。连续快速遮挡、松开约三次，会出现流星彩蛋。
网页还会显示缓慢漂浮的星尘粒子。环境越暗，粒子越清晰、运动越明显。

## 常见故障

| 现象 | 检查方法 |
|---|---|
| 看不到“连接 Arduino 串口”或提示不支持 | 使用最新版桌面版 Chrome；Web Serial 不支持手机浏览器、Safari 和 Firefox。|
| 串口选择窗口没有 Arduino | 换一根 USB 数据线；确认 IDE 能识别端口；部分兼容板需要安装 CH340 驱动。|
| 连接失败 / 端口忙 | 关闭 Arduino 串口监视器、串口绘图器，以及其他正在打开该端口的软件。|
| 网页提示“光线传感器信号丢失” | 该提示表示网页没有收到任何串口数字，不能单独证明 A0 损坏。网页刚连接时 Uno 会自动复位，等待最多 3 秒；若仍提示，先确认草图已上传，再关闭 Arduino 串口监视器和绘图器，最后检查 OUT/AO 是否接 A0、VCC 是否接 5V、GND 是否接 GND。|
| 数字始终为 0 或 1023 | 检查三根线是否松动；传感器可能不支持 5V 或其 AO/DO 标识接错。|
| 明暗视觉方向相反 | 按“硬件接线清单”下方说明调整网页中的 `brightness` 一行。|

提示：Chrome 在某些严格的电脑策略下可能不允许从本地文件调用 Web Serial。若遇到该情况，可将 `index.html` 拖入一个新 Chrome 窗口后重试，或使用 Chrome 的本地文件访问权限设置；项目本身不依赖服务器。
